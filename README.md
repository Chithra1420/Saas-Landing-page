# SaaSPro - Responsive SaaS Landing Page UI

A state-of-the-art, high-converting, and beautiful landing page built with pure semantic HTML5, modern vanilla CSS3, and native JavaScript. It is fully responsive across mobile, tablet, and desktop viewports, featuring elegant glassmorphism, fluid SVG animations, and native dark mode support.

## ✨ Features

- **🎨 High-End Modern Aesthetics**: Built around customizable HSL color tokens, rich gradients, smooth shadows, and polished typography using Google Fonts (**Outfit** for headings and **Inter** for clean body text).
- **🌗 Native Dark/Light Mode**: Persists user choice in browser `localStorage`, with smooth transition shifts.
- **📈 Interactive SVG Dashboard**: 
  - Clicking on features (Workflow Automation, Advanced Analytics, Team Collaboration) morphs the SVG spline charts and changes dashboard numbers.
  - Features an **auto-rotation cycle** every 5 seconds which pauses automatically on mouse hover.
- **✨ Infinite Value Marquee**: Endlessly scrolls core business values (`Better Tools • Better Workflow • Better Growth`) using smooth, performant CSS keyframes.
- **💬 Testimonial Slider Carousel**: Touch-friendly user reviews slider complete with active dot indicators, auto-scroll support, and navigation control arrows.
- **📱 Fully Responsive Design**: Built with clean flexible grids and media queries to adapt flawlessly across all devices (Desktop, iPad/Tablet, and Mobile screens).

---

## 🛠️ Built With

- **HTML5**: Semantic markup tags.
- **CSS3**: Vanilla CSS grids, flexbox layouts, custom variables, keyframe animations, and glassmorphic modules.
- **JavaScript (ES6+)**: Custom interaction, auto-rotating tab showcases, carousel logic, scroll detection, and local storage state persistence.
- **FontAwesome**: Modern web vector icons.
